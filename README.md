# TrainCarts 編成エディター README

## 1. 概要

TrainCartsの列車データを読み込み、ブラウザー上で視覚的に編集・エキスポートするためのツールです。

PHP形式のファイルやYMLデータを読み込み、列車全体・各車両のプロパティを編集できます。

## 2. 起動方法

1. `Index.html` をダウンロードする。
2. ファイルをブラウザーで開く。
3. 列車データが未読み込みの場合、画面中央にインポートボタンが表示されます。

## 3. 列車データのインポート

### Minecraftゲーム内からデータを取得する

1. Minecraft内で以下のコマンドを実行します。

   ```text
   /savedtrain <savedtrainname> export
   ```

   `<savedtrainname>` には取得したい保存済み列車の名前を指定します。

2. コマンド実行後に表示される、以下の形式から始まるURLを開きます。

   `https://paste.traincarts.net/`

3. Hastebinのページが表示されます。
4. ページ右上の「エキスポート」を押してデータを取得するか、ページ内のデータを全体コピーします。

### 管理サイトにインポートする

1. 管理サイトで「インポート」を押します。
2. 表示されたダイアログに取得したデータを貼り付けます。
3. インポートを実行します。
4. 読み込みが成功するとビジュアルエディターが表示されます。

※ HastebinのURLを直接入力するのではなく、Hastebinに表示されたデータを取得して貼り付けます。

### ファイルから読み込む場合

- YMLファイルを選択して読み込めます。
- PHP拡張子のファイルも読み込み対象です。

## 4. ビジュアルエディター

読み込んだ列車を画面上で編集できます。

### 編成編集

- 車両の追加
- 車両の削除
- 車両の順序変更
- 車両のドラッグ移動

### プロパティ編集

列車全体と各車両のプロパティを編集できます。

プロパティは用途ごとにカテゴリ分けされています。

### 表示ブロック

車両に表示するブロックを選択できます。

現在の仮実装では羊毛16色を選択できます。

## 5. エキスポート

編集した列車データをエキスポートできます。

1. 上部の「エキスポート」を押します。
2. 出力されたデータをテキストエリアからコピーするか、PHP形式で保存します。
3. 保存したデータをTrainCarts側で利用します。

## 6. 注意事項

- PHPファイルはPHPプログラムとして実行せず、データファイルとして読み込みます。
- YAMLのすべての構文に対応しているわけではありません。
- 未対応のプロパティが存在する場合があります。
- 読み込んだデータを自動保存する機能はありません。編集後は必要に応じてエキスポートしてください。
